# Проект «Витрина» на Next.js

Учебный проект — витрина интернет-магазина.

## Задание

1. Файл с многомерной структурой данных (товары)
2. Главная страница — список всех товаров (плитка карточек)
3. Страница товара с полным описанием

## Запуск

```bash
npm install
npm run dev
```

Открыть: http://localhost:3000

## Технологии

- Next.js 15 (App Router)
- TypeScript
- CSS Modules
- next/image, next/link
