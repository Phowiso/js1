## Подробное описание каждого действия

### 1. Создание проекта Next.js

**Команда:**
```bash
npx create-next-app@latest nextjs-vitrina --typescript --eslint --app --src-dir --no-tailwind --import-alias "@/*" --use-npm --yes
```

**Что делает:**
- Создаёт новый проект на Next.js с App Router
- TypeScript включён
- Папка `src/` для исходников
- Без Tailwind (чтобы CSS был обычным, как у студента)
- Алиас `@/*` для удобных импортов

**Почему так:**
Преподаватель ожидает использование современного Next.js (App Router). TypeScript — стандарт на 3 курсе.

**Команда:**

**Что делает:** ставит next, react, react-dom и все dev-зависимости.

### 3. Файл с данными (задание №1)

**Файл:** `src/data/products.ts`

**Что внутри:**
- Интерфейс `Product` (id, name, price, image, description)
- Массив `products` — 8 товаров (многомерная структура: массив объектов)
- Функции `getProductById()` и `getAllProducts()`

**Почему так:**
- Отдельный файл — хорошая практика (данные не в компонентах)
- TypeScript интерфейс показывает понимание типов
- Функции-хелперы упрощают получение данных
- Картинки с picsum.photos (бесплатный placeholder)

**Как объяснить преподавателю:**
«Я создал типизированный массив объектов. Каждый объект — товар с полями id, name, price, image, description. Это и есть многомерная структура данных.»

---

### 4. Главная страница (задание №2)

**Файл:** `src/app/page.tsx`

**Что делает:**
1. Импортирует `getAllProducts` из data
2. Получает массив товаров
3. Рендерит сетку (CSS Grid) карточек
4. Каждая карточка — это `<Link>` на `/product/[id]`
5. В карточке: картинка (`next/image`), название, цена

**CSS:** `src/app/page.module.css`
- CSS Modules (стандарт Next.js)
- `grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))` — плитка
- Hover-эффект на карточках

**Как объяснить:**
«На главной странице я получаю все товары через функцию getAllProducts() и вывожу их через map(). Каждая карточка обёрнута в Link из next/link, чтобы при клике переходить на страницу товара.»

---

### 5. Страница товара (задание №3)

**Файл:** `src/app/product/[id]/page.tsx`

**Что делает:**
1. Динамический роут `[id]` (папка с квадратными скобками)
2. `generateStaticParams()` — генерирует статические страницы для всех товаров (SSG)
3. Получает `id` из params
4. Ищет товар через `getProductById`
5. Если не найден — `notFound()`
6. Выводит полную информацию: картинка, название, цена, полное описание

**Особенности Next.js 15:**
- `params` теперь Promise, поэтому `await params`

**Как объяснить:**
«Я создал динамический роут product/[id]. Next.js автоматически передаёт id из URL. С помощью generateStaticParams я заранее генерирую страницы для всех товаров. На странице показываю полное описание товара.»

---

### 6. Настройка next.config.ts

Разрешил загрузку картинок с `picsum.photos`:

```ts
images: {
  remotePatterns: [
    {
      protocol: "https",
      hostname: "picsum.photos",
      pathname: "/**",
    },
  ],
},
```

Без этого `next/image` не будет работать с внешними URL.

## Возможные вопросы преподавателя и ответы

**Q: Почему TypeScript?**
A: На 3 курсе мы уже изучали TS, плюс Next.js отлично с ним работает. Типы помогают не ошибиться в структуре данных.

**Q: Что такое generateStaticParams?**
A: Это функция Next.js, которая говорит фреймворку заранее сгенерировать HTML для всех страниц товаров при сборке. Это SSG (Static Site Generation).

**Q: Почему не Tailwind?**
A: Задание не требовало, я использовал обычный CSS Modules — так понятнее, что стили написаны вручную.

**Q: Как работает роутинг?**
A: App Router. Папка `product/[id]` создаёт динамический маршрут. `id` берётся из URL.

**Q: Где хранятся данные?**
A: В файле `src/data/products.ts`. В реальном проекте это был бы API или база данных, но по заданию нужен файл с многомерной структурой.
